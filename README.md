[![UI: Material 3](https://img.shields.io/badge/UI-Material%203-teal.svg)](https://m3.material.io/)

**Plantshelf** — це відкритий (Open Source), безпечний та офлайн-орієнтований додаток для догляду за кімнатними рослинами під Android.

Додаток створено як вільну альтернативу комерційним рішенням (зокрема Brunq), з фокусом на повну приватність користувача, локальне збереження даних на вашому пристрої та відмову від платних підписок. Усі дані зберігаються локально; зовнішній AI (Google Gemini) використовується виключно за бажанням користувача з власним безкоштовним ключем.

> [!TIP]
> **Архітектура**: Весь код додатка написаний на **чистій Java 17** без використання Kotlin, із дотриманням принципів відкритого коду, автономності та високої швидкодії.

## ✨ Основні можливості

- 🪴 **Організація по кімнатах («Полицях»)**: зручне групування рослин за кімнатами (вітальня, кухня, спальня тощо) з власними кольорами та іконками.
- 📖 **Вбудована «Енциклопедія рослин»**: каталог поширених кімнатних рослин (Монстери, Фікуси, Заміокулькаси, Спатифілуми, Сансевієрії, Орхідеї тощо) з верифікованими параметрами догляду та кнопкою **«➕ Додати на полицю»** в один дотик.
- 🤖 **Швидке додавання з Gemini в 1 клік**: просто введіть назву рослини або сфотографуйте її — Gemini самостійно розрахує графік поливу, рівень люксів, вимоги до ґрунту та одразу збереже рослину у вибрану кімнату.
- 📸 **Фото з камери та галереї**: вбудована підтримка вибору знімків з галереї та швидкої фотозйомки через камеру із збереженням у внутрішнє захищене сховище.
- 🔍 **Живий пошук**: миттєва фільтрація рослин на головному екрані за назвою, сортом, народною або латинською назвою.
- 📅 **Календар догляду та Інтеграція з Google / системним календарем**:
  - Наочний внутрішній календар на будь-який день місяця з відміткою виконання завдань.
  - Пряме створення регулярних нагадувань у системному календарі Android / Google Calendar з автоматичним розрахунком дат і правилом повторення (`RRULE`).
  - Експорт графіка догляду всієї оранжереї у файл стандарту `.ics` (iCalendar) для синхронізації з будь-якими календарями (Google, Outlook, Apple Calendar).
- 🌿 **AI-розпізнавання рослин за фото (Google Gemini)**: автоматичне визначення виду за знімком через безкоштовний Gemini API з детальним автозаповненням характеристик.
- ⏰ **Розумний графік догляду**:
  - Роздільні інтервали для **літнього** та **зимового** сезону поливу.
  - Календар внесення добрив та обприскування.
  - Наочні статуси терміновості: *«Полити сьогодні»*, *«Через N днів»*, *«Прострочено»*, а також режим *«Карантин»*.
- ⚡ **Швидкі дії в 1 клік**: швидка фіксація поливу або обприскування прямо зі списку рослин без відкриття додаткових меню.
- 💡 **Вбудований люксметр**: вимірювання реального рівня освітленості біля рослини за допомогою системного апаратного сенсора `Sensor.TYPE_LIGHT` з підказками про відповідність нормі.
- 📖 **Детальна картка рослини**: інформація про сорт, латинську назву, рецепт ґрунту, розмір горщика, вологість та застереження щодо безпеки для тварин.
- 📜 **Журнал догляду**: повна історія всіх поливів, обприскувань та внесення добрив з точними датами та часом.
- 📱 **Віджет для робочого столу (AppWidget)**: інформативний віджет на головний екран смартфона, що показує рослини, які потребують поливу чи догляду сьогодні, з прямим переходом у картку та кнопкою оновлення.
- 🏥 **Режим карантину та боротьба зі шкідниками**:
  - Швидкий фільтр «⚠️ Карантин» на головному екрані з лічильником ізольованих рослин.
  - Картка статусу карантину з причиною та розрахунком дати завершення.
  - Журнал лікування: фіксація обробки препаратами (Актара, Фітоверм, Топаз тощо) з дозуванням і нотатками.
- 🚀 **Оновлення прямо з GitHub (In-App Updater)**:
  - Фонова тиха перевірка оновлень (не частіше одного разу на 24 години при холодному старті) та ручна перевірка в один дотик через меню.
  - Завантаження свіжого `.apk` у фоні та встановлення через нативний системний інсталятор Android.
  - Повна приватність: жодної телеметрії чи передачі даних користувача — лише анонімний запит версії з офіційного GitHub Releases API.
- ⚙️ **CI/CD та скрипти автоматизації**:
  - Економний GitHub Actions workflow (збірка тільки за тегами `v*` або вручну, 0 зайвих витрат безкоштовних лімітів).
  - Локальний скрипт `build_and_deploy.bat` / `.ps1` для 1-клік тестування на емуляторі та публікації релізів.
- 🔄 **Повна сумісність із бекапами Brunq**:
  - Імпорт наявних бекапів Brunq (`.json`) усім масивом (кімнати, рослини, розклади, історія догляду).
  - Автоматичне вилучення Base64-фотографій з бекапу у локальне сховище без перевантаження оперативної пам'яті.
  - Експорт бази в сумісний JSON для надійного резервного копіювання.
- 🔔 **Фонові сповіщення**: щоденна тиха перевірка стану через `WorkManager` без зайвого розряду батареї.

## 🛠 Технологічний стек

- **Мова програмування**: Pure Java (Java 17).
- **Інтерфейс користувача**: Material Design 3, XML Layouts, ViewBinding, CoordinatorLayout + CollapsingToolbar.
- **База даних**: AndroidX Room (SQLite) з DAO та повноцінними індексами.
- **Архітектура**: Android Architecture Components (MVVM, ViewModel, LiveData, Repository pattern).
- **Фонова робота**: AndroidX WorkManager.
- **Робота з фото**: Bumptech Glide.
- **Парсинг та робота з даними**: Google Gson.
- **Датчики**: Android Hardware SensorManager (`TYPE_LIGHT`).

### ☕ Чому Pure Java 17?

Проєкт свідомо написаний на **чистій Java 17** без залежностей від Kotlin runtime:
1. **Незалежність від екосистеми JetBrains**: Відсутність прив'язки до швидких релізних циклів Kotlin-компілятора, версій KSP або раптових breaking changes рантайму мови.
2. **Передбачуваність байт-коду та швидкодія**: Компілятор `javac` створює прозорий, компактний і детермінований байт-код без надлишкових синтетичних обгорток, що забезпечує мінімальний розмір APK та блискавичний час збірки.
3. **Довговічність та надійність (LTS)**: Java 17 — це промисловий Long-Term Support стандарт. Код залишатиметься стабільним, підтримуваним і сумісним десятиліттями без необхідності нескінченних вимушених рефакторингів.

## 🚀 Як відкрити та зібрати проєкт

### В Android Studio:
1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/Homka13/Plantshelf.git
   ```
2. Відкрийте Android Studio та оберіть **File -> Open...** -> вкажіть папку проєкту `Plantshelf`.
3. Зачекайте завершення Gradle Sync.
4. Запустіть додаток на емуляторі або підключеному Android-пристрої (Shift + F10).

### Збірка через командний рядок (CLI):
- Windows:
  ```cmd
  .\gradlew.bat assembleDebug
  ```
- Linux / macOS:
  ```bash
  ./gradlew assembleDebug
  ```
Зібраний файл APK з'явиться за шляхом: `app/build/outputs/apk/debug/app-debug.apk`.
